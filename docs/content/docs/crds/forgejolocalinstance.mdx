- **API version:** `forgejo.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `fjli`
- **Guide:** [A namespace's own instance](/docs/guides/connect-instance#a-namespaces-own-instance)

Connection to a real Forgejo server (v16 or later), owned by a
namespace: its token is that namespace's, and only the objects of this
namespace use it unless `sharedWith` says otherwise. What an operator
limited to one namespace uses. Objects bound to it are not governed by
`ForgejoNamespacePolicy` — the namespace's own token bounds what they
can do — and write their secrets as Kubernetes `Secret`s only: the
operator's Vault identity is shared by every namespace.

## Example

```yaml
apiVersion: forgejo.weebo.io/v1alpha1
kind: ForgejoLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  url: https://git.example.com
  tokenSecretRef:
    name: forgejo-token
    key: token
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| [`sharedWith`](#spec.sharedWith) | `object` | no |  | Other namespaces (or cluster-scoped objects) allowed to use this instance — and its token. Unset: this namespace only. |
| [`tls`](#spec.tls) | `object` | no | `{"insecureSkipVerify":false}` | TLS verification for the API connection above; the CA `Secret` lives in this namespace. |
| [`tokenSecretRef`](#spec.tokenSecretRef) | `object` | yes |  | Key of a `Secret` of this namespace holding the API token the operator acts with (a site admin's for user and organization management). Re-read on every gateway call, so rotating it needs no restart. The `Secret` must carry the label `forgejo.weebo.io/instance-token: "true"`: the operator reads it with its own rights, so only a Secret labelled for that use is ever sent to the instance's URL. |
| `url` | `string` | yes |  | Base web URL of the Forgejo instance, e.g. `https://git.example.com` — not the `/api/v1` REST endpoint, which is derived from it. Written as `FORGEJO_URL` into emitted secrets. |

### `spec.sharedWith` [#spec.sharedWith]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `clusterScoped` | `boolean` | no |  | Cluster-scoped objects may use this instance. |
| [`namespaceSelector`](#spec.sharedWith.namespaceSelector) | `object` | no |  | Namespaces whose labels match this selector may use this instance. An empty selector (`{}`) matches every namespace: the instance — and the token it holds — is then shared with the whole cluster. |
| `namespaces` | `string[]` | no |  | Namespaces whose objects may use this instance. |

### `spec.sharedWith.namespaceSelector` [#spec.sharedWith.namespaceSelector]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| [`matchExpressions`](#spec.sharedWith.namespaceSelector.matchExpressions) | `object[]` | no |  | matchExpressions is a list of label selector requirements. The requirements are ANDed. |
| `matchLabels` | `map[string]` | no |  | matchLabels is a map of \{key,value\} pairs. A single \{key,value\} in the matchLabels map is equivalent to an element of matchExpressions, whose key field is "key", the operator is "In", and the values array contains only "value". The requirements are ANDed. |

### `spec.sharedWith.namespaceSelector.matchExpressions[]` [#spec.sharedWith.namespaceSelector.matchExpressions]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `key` | `string` | yes |  | key is the label key that the selector applies to. |
| `operator` | `string` | yes |  | operator represents a key's relationship to a set of values. Valid operators are In, NotIn, Exists and DoesNotExist. |
| `values` | `string[]` | no |  | values is an array of string values. If the operator is In or NotIn, the values array must be non-empty. If the operator is Exists or DoesNotExist, the values array must be empty. This array is replaced during a strategic merge patch. |

### `spec.tls` [#spec.tls]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| [`caSecretRef`](#spec.tls.caSecretRef) | `object` | no |  | Optional custom CA certificate (a PEM bundle under `key`) to verify the instance's TLS with, read from a `Secret` of the instance's own namespace. Added on top of the platform trust store. |
| `insecureSkipVerify` | `boolean` | no | `false` | Skip certificate verification entirely — insecure, intended only for throwaway/self-signed instances. Prefer `caSecretRef` below. |
