- **API version:** `forgejo.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `fjorg`
- **Guide:** [Users, OIDC and teams](/docs/guides/users-and-oidc#organizations-and-teams)

A Forgejo organization.

## Example

```yaml
apiVersion: forgejo.weebo.io/v1alpha1
kind: ForgejoOrganization
metadata:
  name: my-organization
  namespace: team-a
spec:
  name: weebo
  visibility: private
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `deletionPolicy` | `string` | no | `"Orphan"` | Defaults to `Orphan`: deleting the CR never deletes the organization (Forgejo also refuses while it still owns repos). |
| `description` | `string` | no |  |  |
| `email` | `string` | no |  |  |
| `fullName` | `string` | no |  |  |
| `instanceRef` | `object` | no |  | The `ForgejoInstance` or `ForgejoLocalInstance` this object lives on. Unset: the cluster's only `ForgejoInstance`, else the only `ForgejoLocalInstance` of this namespace. |
| `location` | `string` | no |  |  |
| `name` | `string` | yes |  | Organization name (its URL slug). Changing it renames in place. |
| `ownerRef` | `object` | no |  | The user that becomes the organization's first owner. Only read at creation; without it the operator's admin account owns it. |
| `repoAdminChangeTeamAccess` | `boolean` | no | `false` | Let repository admins change which teams can access their repo. |
| `sharedWith` | `object` | no |  | Other namespaces allowed to reference this object (when the operator enables cross-namespace references). Unset: this namespace only. |
| `visibility` | `string` | no | `"public"` | Visibility of a Forgejo user or organization. |
| `website` | `string` | no |  |  |
