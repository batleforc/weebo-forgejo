- **API version:** `forgejo.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `fjukey`
- **Guide:** [Users, OIDC and teams](/docs/guides/users-and-oidc#ssh-keys-for-a-user)

An SSH public key of a user — typically a bot's. Same key handling as
`ForgejoDeployKey`.

## Example

```yaml
apiVersion: forgejo.weebo.io/v1alpha1
kind: ForgejoUserKey
metadata:
  name: my-userkey
  namespace: team-a
spec:
  userRef:
    name: ci-bot
  title: ci
  secretTargets:
    - name: ci-bot-ssh
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `deletionPolicy` | `string` | no | `"Delete"` | What happens to the Forgejo object when its CR is deleted. |
| `instanceRef` | `object` | no |  | The `ForgejoInstance` or `ForgejoLocalInstance` this object lives on. Unset: the cluster's only `ForgejoInstance`, else the only `ForgejoLocalInstance` of this namespace. |
| `publicKey` | `string` | no |  | An OpenSSH public key (`ssh-ed25519 AAAA... comment`). Unset: the operator generates an ed25519 pair. |
| `secretTargets` | `object[]` | no |  | Destinations of a generated private key. Required when `publicKey` is unset; a target that disappears (or a new `forgejo.weebo.io/rotate-secret` nonce) generates a fresh pair. |
| `title` | `string` | no |  | Defaults to the CR name. |
| `userRef` | `object` | yes |  | A user, organization or team: a CR (`name`) — of this object's namespace, or of `namespace` when cross-namespace references are enabled for the operator and the target lists this namespace in its `sharedWith` — or an object that exists in Forgejo but no CR manages (`remoteName`, its Forgejo name). The operator never creates, changes nor deletes a `remoteName` object. |
