- **API version:** `forgejo.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `fjukey`
- **Guide:** [Users, OIDC and teams](/docs/guides/users-and-oidc#ssh-keys-for-a-user)

An SSH public key of a user — typically a bot's. Same key handling as
`ForgejoDeployKey`.

## Example

```yaml
apiVersion: forgejo.weebo.io/v1alpha1
kind: ForgejoUserKey
metadata:
  name: my-userkey
  namespace: team-a
spec:
  userRef:
    name: ci-bot
  title: ci
  secretTargets:
    - name: ci-bot-ssh
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `deletionPolicy` | `string` | no | `"Delete"` | What happens to the Forgejo object when its CR is deleted.<br /><br />Values: `"Delete"`, `"Orphan"` |
| [`instanceRef`](#spec.instanceRef) | `object` | no |  | The `ForgejoInstance` or `ForgejoLocalInstance` this object lives on. Unset: the cluster's only `ForgejoInstance`, else the only `ForgejoLocalInstance` of this namespace. |
| `publicKey` | `string` | no |  | An OpenSSH public key (`ssh-ed25519 AAAA... comment`). Unset: the operator generates an ed25519 pair. |
| [`secretTargets`](#spec.secretTargets) | `object[]` | no |  | Destinations of a generated private key. Required when `publicKey` is unset; a target that disappears (or a new `forgejo.weebo.io/rotate-secret` nonce) generates a fresh pair. |
| `title` | `string` | no |  | Defaults to the CR name. |
| [`userRef`](#spec.userRef) | `object` | yes |  | A user, organization or team: a CR (`name`) — of this object's namespace, or of `namespace` when cross-namespace references are enabled for the operator and the target lists this namespace in its `sharedWith` — or an object that exists in Forgejo but no CR manages (`remoteName`, its Forgejo name). The operator never creates, changes nor deletes a `remoteName` object. |

### `spec.instanceRef` [#spec.instanceRef]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `kind` | `string` | no |  | The kind of instance a reference designates.<br /><br />Values: `"Instance"`, `"LocalInstance"` |
| `name` | `string` | yes |  | `metadata.name` of the instance. |
| `namespace` | `string` | no |  | Namespace of a `LocalInstance`. Defaults to this object's own; required on a cluster-scoped object. Another namespace's local instance must share itself with this one (its `sharedWith`). |

**Rules**

- namespace only applies to kind LocalInstance — `!has(self.namespace) || !has(self.kind) || self.kind == 'LocalInstance'`

### `spec.secretTargets[]` [#spec.secretTargets]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `backend` | `string` | no | `"kubernetes"` | `kubernetes` (default) or `vault`. A Vault target reuses the Vault connection (address, mount, auth) the instance configures, which it must then do.<br /><br />Values: `"kubernetes"`, `"vault"` |
| `name` | `string` | yes |  | Kubernetes: the `Secret` name. Vault: names the default path `<pathPrefix>/<namespace>/<name>` when `path` is unset. |
| `namespace` | `string` | no |  | Kubernetes `Secret` namespace (Vault: the namespace segment of the default path). Defaults to the CR's own namespace; required on cluster-scoped CRs. A namespaced CR may only name its own namespace. |
| `path` | `string` | no |  | Vault only: explicit KV v2 path under the instance's mount. It must stay under `<pathPrefix>/<namespace>/` (this object's namespace, or the target's on a cluster-scoped object), unless the instance's `pathGrants` open it to this object. |

### `spec.userRef` [#spec.userRef]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `name` | `string` | no |  | `metadata.name` of the CR. |
| `namespace` | `string` | no |  | Namespace of the CR; defaults to this object's own. |
| `remoteName` | `string` | no |  | Forgejo name of an object no CR manages (a user's login, an organization's or team's name). |

**Rules**

- set exactly one of name and remoteName — `has(self.name) != has(self.remoteName)`
- namespace only applies with name — `!has(self.namespace) || has(self.name)`
