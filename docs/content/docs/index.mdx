---
title: weebo-forgejo-operator
description: A Kubernetes operator that manages Forgejo as CRDs.
---

`weebo-forgejo-operator` manages the objects *inside* an existing Forgejo
(v16 or later) — users, organizations, teams, repositories, webhooks, SSH
keys, OAuth2 applications and access tokens — as Kubernetes custom
resources. Forgejo itself stays deployed by its own Helm chart.

- **The CR is authoritative**: drift made in the Forgejo UI is corrected on
  the next reconcile, and updates are only sent when something differs.
- **No implicit adoption**: a name already taken in Forgejo is reported
  (`ForgejoObjectAlreadyExists`), never silently taken over.
- **Secrets out**: generated passwords and keys, OAuth2 credentials and
  tokens are written to Kubernetes Secrets and/or Vault.
- **Namespace allow-list**: which namespace may create what, in which
  organization, for which user — enforced by an admission webhook and
  re-checked by every reconciler.
